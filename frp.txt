启动容器
docker run -d --name frps --restart always --network host -v /etc/frp/frps.toml:/etc/frp/frps.toml snowdreamtech/frps

android客户端
下载apk https://github.com/sky22333/frp-android/releases/tag/v0.0.1 ,并安装
打开软件
配置-新建-frpc

serverAddr = "101.120.xxx.xxx"
serverPort = 7000
auth.token = "服务端设置的令牌token"

[[proxies]]
name = "android-socks5"
type = "tcp"
localPort = 7001
remotePort = 7001          # 公网服务器监听port 7001
[proxies.plugin]
type = "socks5"
